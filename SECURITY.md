# Security Policy

This repository is a research notebook for coordinated vulnerability disclosure work on Zyxel WAX650S firmware `V7.10(ABRM.4)C0`.

## Scope

The public tree is documentation-first. It contains selected summaries, evidence notes, and benign reproduction helpers. It intentionally excludes raw firmware, live secrets, private disclosure correspondence, and weaponized exploit tooling.

## Responsible Use

Use the material only on systems you own, operate, or are explicitly authorized to test. The open-redirect PoC is designed as a non-collecting demonstration page; do not convert it into credential collection or deceptive production use.

## Disclosure Status

This snapshot is prepared for publication after the relevant coordinated disclosure window allows release. If you are reviewing it before publication, treat the content as embargoed research material.
