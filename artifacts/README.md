# Artifacts

This directory contains the public-safe evidence subset for the Zyxel WAX650S research notebook.

Included material is limited to:

- summary-grade dynamic artifacts that document behavior without bulk traces;
- report-ready evidence notes;
- a benign open-redirect demonstration package;
- selected helper references needed to understand the lab workflow.

Excluded material includes raw firmware, extracted rootfs trees, live process state, packet captures, private disclosure correspondence, generated session tokens, and superseded drafts with outdated impact language.
